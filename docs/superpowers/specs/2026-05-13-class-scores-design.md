# 班级分值看板页面设计

## 概述

将现有的 `ClassScores.vue` 页面从简单表格样式升级为修仙风格的看板界面，以卡片形式展示每个学生的境界状态。

## 现有页面分析

- **文件**：`repos/frontend/src/views/teacher/ClassScores.vue`
- **当前功能**：班级选择下拉 + 学生卡片网格（姓名、段位图片、段位名称、距下一段位分数）
- **当前样式**：简单白底卡片，缺少视觉冲击力

## 设计目标

1. 采用玄秘江湖风（紫黑底色 + 金色点缀）
2. 保留现有功能逻辑（班级选择、学生数据计算）
3. 提升视觉体验，符合修仙世界观

## 视觉规范

### 配色方案

| 元素 | 颜色 | 用途 |
|------|------|------|
| 背景渐变 | `rgba(26,10,46,0.95)` → `rgba(60,30,90,0.9)` | 卡片背景 |
| 边框高光 | `rgba(255,215,0,0.4)` | 普通卡片边框 |
| 最高境界边框 | `#ffd700` | 最高境界学生卡片 |
| 主强调色 | `#ffd700` | 标题、积分数字、装饰 |
| 境界标签-高 | `linear-gradient(#22c55e, #16a34a)` | 筑基境等 |
| 境界标签-低 | `linear-gradient(#86efac, #22c55e)` | 启灵境等 |
| 进度条 | `linear-gradient(#22c55e, #86efac)` | 境界进度 |

### 布局结构

```
页面标题 ("班级分值看板")
副标题 ("弟子修为一览")
装饰分隔线 (金色渐变)
班级选择器
卡片网格 (auto-fill, minmax(200px, 1fr))
  └── 每个卡片:
      - 顶部光晕效果 (position: absolute)
      - 境界图片 (90x90px, drop-shadow光效)
      - 境界角标 (右下角, 圆角标签)
      - 学生姓名
      - 进度条 (距下一境界分数)
底部装饰
```

### 卡片设计

| 状态 | 样式差异 |
|------|----------|
| 普通 | 紫色渐变背景 + 金色边框 1px |
| 最高境界 | 金色边框 2px + 发光阴影 + "最高境界"标签 + 头像脉冲动画 |

### 字体规范

- 页面标题：24px, `#fff`
- 副标题：14px, `rgba(255,255,255,0.6)`
- 学生姓名：18px, `#fff`, font-weight 600
- 进度文字：11px, white, text-shadow

### 动画效果

- 最高境界头像：`animation: pulse 2s infinite` (缩放 1.0 ↔ 1.05)
- 卡片入场：无（保持性能）

## 数据结构

保留现有接口和数据结构不变：
- `current_score` → 计算当前境界和下一境界
- `rank_image` → `/pics/X.png` 境界图片
- `rank_name` → 境界名称
- `next_rank_name` → 下一境界名称
- `score_to_next` → 距下一境界分数

## 实现注意事项

1. **进度条宽度**：根据当前积分占下一境界的比例计算，而非固定值
2. **最高境界判断**：当 `next_rank_name` 为 null 时显示"已达最高境界"
3. **图片路径**：使用 `/pics/X.png`，需要确认 public 目录下的图片可访问
4. **Element Plus 兼容**：当前使用 el-select 保持，下拉选项自定义样式可能受限
