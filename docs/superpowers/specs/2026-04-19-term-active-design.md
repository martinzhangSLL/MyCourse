# 学期有效状态 + 积分关联学期 设计

## 1. 背景与目标

**目标：**
1. 学期新增 `is_active` 字段，标识是否为当前有效学期
2. 所有学期只允许一个有效学期，激活新学期时自动将其他学期置为非激活
3. 积分记录关联学期，加减分时自动记录所属学期
4. 按学期排序时可从 `term_id` 直接读取学期起止日期

**现有问题：**
- 学期无法标识"当前学期"，积分记录无法关联具体学期
- 按学期统计排序时依赖时间计算，不够直接

## 2. 数据库变更

### 2.1 Term 表

新增字段：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| is_active | Boolean | False | 是否当前有效学期 |

### 2.2 ScoreRecord 表

新增字段：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| term_id | Integer (FK term.id) | nullable | 关联的学期 ID |

### 2.3 数据修复

- 默认当前数据库第一条学期记录 `is_active=True`
- 默认所有现有积分记录 `term_id` 指向该学期

## 3. 后端变更

### 3.1 Schema 变更

**TermResponse** 新增字段：
```python
is_active: bool
```

**TermCreate / TermUpdate** 保持不变

**ScoreCreate / ScoreResponse** 新增字段：
```python
term_id: int | None = None
```

### 3.2 新增 API

**激活学期**
```
PUT /api/config/terms/{term_id}/activate
```

逻辑：
1. 校验学期日期已配置（start_date 和 end_date 都存在）
2. 将该学期 `is_active` 设为 `True`
3. 将其他所有学期 `is_active` 设为 `False`
4. 事务保证原子性

返回：
```json
{
  "id": 1,
  "name": "2025-2026学年上学期",
  "year": "2025-2026",
  "start_date": "2025-09-01",
  "end_date": "2026-01-31",
  "is_active": true
}
```

**获取当前有效学期**
```
GET /api/config/terms/current
```

返回当前 `is_active=True` 的学期（含日期范围），无有效学期返回 404。

### 3.3 修改现有 API

**删除学期**
- 禁止删除 `is_active=True` 的学期
- 返回 403，提示"请先激活其他学期"

**创建积分记录**
- 校验存在有效学期，无则返回 403，提示"请先激活一个学期"
- 自动写入当前有效学期的 `term_id`

**获取积分记录列表**
- 支持按 `term_id` 筛选

## 4. 前端变更

### 4.1 ConfigManage.vue

**学期列表表格新增列：**
- `is_active` 标识（当前有效学期显示特殊标记）

**操作列调整：**
- "激活"按钮（仅非激活学期显示，点击后激活）
- 删除按钮保持不变（后端已禁止删除有效学期）

### 4.2 Scores.vue / ScoreDialog.vue

积分记录响应中展示学期信息（可选，展示名称）。

## 5. 约束条件

1. 所有学期只允许一个 `is_active=True`
2. 激活学期时必须校验日期已完整配置
3. 删除学期时必须先激活其他学期
4. 无有效学期时禁止积分操作
5. 积分记录自动关联当前有效学期
