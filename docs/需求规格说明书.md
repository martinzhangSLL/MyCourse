# 初中班级积分管理系统 — 需求规格说明书

> 本文档用于需求层面确认，是设计和开发的依据。

---

## 1. 项目概述

### 1.1 项目名称
初中班级积分管理系统

### 1.2 背景与目标
为了更好地管理初中班级，激励学生学习，提高班级效率，开发一个积分管理系统。教师可以实时针对学生的正面行为和负面行为给学生分配积分，并可查看学生积分排名。支持按周、月、学期进行统计和排名。

### 1.3 用户角色

| 角色 | 数量 | 说明 |
|------|------|------|
| 管理员 | 1 人 | 单一账号，负责系统基础数据管理、结算、初始化 |
| 教师 | 1 人/班级 | 负责积分加减、查看排名和明细 |

> **扩展预留**：数据库层面教师与班级支持多对多，未来可实现一个教师管理多个班级。

## 2. 功能需求

### 2.1 基础管理功能（管理员）

#### 2.1.1 管理员登录
- 管理员通过账号密码登录系统
- 系统根据角色（管理员/教师）展示不同页面菜单

#### 2.1.2 班级管理
- **查询**：查看所有班级列表
- **新增**：录入班级名称、班级编号、关联教师、关联课程
- **编辑**：修改班级名称、班级编号、关联教师、关联课程
- **删除**：逻辑删除（同时删除该班级关联的教师、学生、课程关系）
- **激活**：班级信息完整（已有学生）后，管理员可点击"激活"按钮
  - 激活后，该班级**禁止**通过 Excel 方式导入学生，只能在页面进行增删改查

#### 2.1.3 学生管理
- **查询**：按班级查看学生列表，显示学号、姓名、当前积分
- **新增**：单独添加学生（姓名、学号、所属班级）
- **导入**：上传 Excel 批量导入学生（Excel 格式：第一列学生姓名，第二列学生学号）
  - 仅在班级**未激活**时可导入，激活后禁止导入
- **编辑**：修改学生姓名、学号
- **删除**：删除学生（同时删除该学生的积分记录）

#### 2.1.4 教师管理
- **查询**：查看所有教师列表
- **新增**：录入教师姓名、初始密码
- **编辑**：修改教师姓名、密码
- **删除**：删除教师

> **扩展预留**：数据库层面教师与班级为多对多，支持一个教师管理多个班级。

#### 2.1.5 课程管理
- **查询**：查看所有课程列表
- **新增**：录入课程名称
- **编辑**：修改课程名称
- **删除**：删除课程

> **扩展预留**：数据库层面课程与教师为一对多，班级与课程为多对多。

#### 2.1.6 配置管理
- **学期设置**：设置每学期名称、学年、开始日期、结束日期
  - 用于周排名（第1周、第2周…按自然周推算）和学期排名
- **积分原因**：预设加分/扣分原因列表（如：考试、作业、荣誉、其他）
  - 教师在加减分时可从下拉列表选择，也可以手动自填
- **确认码**：设置结算确认码、初始化确认码（管理员独知，用于敏感操作二次验证）

#### 2.1.7 结算
- 管理员选择一个班级进行结算
- 结算前需输入确认码验证（确认码错误则操作失败）
- 结算时需校验：当前学期是否已设置结束日期
  - 若学期未结束（当前日期 < 学期结束日期），弹出提示，拒绝结算
  - 若学期已结束或未设置学期，正常结算
- 结算内容：
  - 导出该班级所有学生的积分排名 Excel（含加减分明细）
  - 逻辑删除该班级所有积分记录
  - 重置班级学生当前积分为零

#### 2.1.8 积分初始化
- 管理员选择一个班级进行积分初始化
- 初始化前需输入确认码验证
- 操作方式：上传 Excel（第一列学生姓名，第二列学生学号，第三列初始积分）
- 系统将对应学生的当前积分设置为初始值

---

### 2.2 教师功能

#### 2.2.1 教师登录
- 教师通过账号密码登录
- 登录后只能看到自己所管理的班级

#### 2.2.2 分值管理（核心页面）
- **班级和课程选择**：页面上方有下拉菜单，选择当前班级和所教课程
- **学生展示**：选择班级和课程后，中间区域以方格展示所有学生
  - 每个方格显示：学号（上方）、姓名（中间）、当前积分（右侧）
  - 方格排列整齐，响应式适配电脑和平板
- **加减分**：点击学生方格，弹出弹窗
  - 显示学生信息（姓名、学号、当前积分）
  - 类型选择：加分 / 扣分 选项卡（默认加分）
  - 分值输入：大输入框，只输入数字
  - 分值颜色：加分时字体显示绿色，扣分时字体显示红色
  - 原因选择：下拉选择预设原因，或手动填写原因
  - 点击确认后，分值（带正负号）和原因保存到数据库，同时更新该学生当前积分

#### 2.2.3 实时排名
- 显示当前班级学生的积分排名
- 排名根据积分从高到低排序
- 支持按不同维度查看排名：
  | 维度 | 计算规则 |
  |------|---------|
  | 总排名 | 初始积分 + 所有加减分 |
  | 周排名 | 选定周内的加减分 |
  | 月排名 | 选定月内的加减分 |
  | 学期排名 | 本学期内的加减分 |
- 周的划分：以学期设置中的开始日期为起点，按自然周计算（第1周、第2周…）
- 导出：支持将排名导出为 Excel 文件

#### 2.2.4 分值明细
- 教师输入班级，系统加载该班所有学生的积分明细
- 明细内容：学生姓名、学号、加减分值、加减分原因、所属课程、操作教师、记录时间
- 支持按时间范围筛选

## 3. 数据字典

### 3.1 班级 (class)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | VARCHAR(50) | 班级名称，如"初三(2)班" |
| code | VARCHAR(20) | 班级编号，唯一 |
| is_active | BOOLEAN | 是否已激活（激活后禁止Excel导入） |
| created_at | DATETIME | 创建时间 |

### 3.2 学生 (student)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | VARCHAR(50) | 学生姓名 |
| student_no | VARCHAR(20) | 学号 |
| created_at | DATETIME | 创建时间 |

### 3.3 学生-班级关联 (student_class)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| student_id | INTEGER | 学生ID，外键 |
| class_id | INTEGER | 班级ID，外键 |
| is_active | BOOLEAN | 是否激活 |
| current_score | INTEGER | 当前积分（冗余字段，加速查询） |

### 3.4 教师 (teacher)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | VARCHAR(50) | 教师姓名 |
| password | VARCHAR(255) | 密码（bcrypt哈希） |
| created_at | DATETIME | 创建时间 |

### 3.5 教师-班级关联 (teacher_class)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| teacher_id | INTEGER | 教师ID，外键 |
| class_id | INTEGER | 班级ID，外键 |

### 3.6 课程 (course)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | VARCHAR(50) | 课程名称 |

### 3.7 班级-课程关联 (class_course)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| class_id | INTEGER | 班级ID，外键 |
| course_id | INTEGER | 课程ID，外键 |

### 3.8 积分记录 (score_record)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| student_id | INTEGER | 学生ID，外键 |
| value | INTEGER | 分值（正数加分，负数扣分） |
| reason | VARCHAR(200) | 加减分原因 |
| course_id | INTEGER | 课程ID，外键 |
| teacher_id | INTEGER | 教师ID，外键 |
| score_at | DATETIME | 积分发生时间 |
| created_at | DATETIME | 记录创建时间 |

### 3.9 学期 (term)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| name | VARCHAR(50) | 学期名称，如"2025-2026学年上学期" |
| year | VARCHAR(20) | 学年，如"2025-2026" |

### 3.10 学期设置 (term_setting)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INTEGER | 主键，自增 |
| term_id | INTEGER | 学期ID，外键 |
| start_date | DATE | 学期开始日期 |
| end_date | DATE | 学期结束日期 |

### 3.11 系统配置 (config)
| 字段名 | 类型 | 说明 |
|--------|------|------|
| key | VARCHAR(50) | 配置键（主键） |
| value | VARCHAR(255) | 配置值 |

> 初始配置项：
> - `settlement_code`：结算确认码
> - `init_code`：初始化确认码
> - `reasons`：加分/扣分原因列表（JSON数组）

## 4. 非功能需求

### 4.1 页面设计
- **风格**：活力绿色游戏风，迎合初中生审美，简洁大方
- **操作友好**：按钮要大（方便点击），输入框要大（方便输入），操作路径要短
- **响应式**：同时兼容电脑（鼠标操作）和平板（触摸操作）

### 4.2 技术要求
- **前端**：Vue 3 + Element Plus + TypeScript
- **后端**：Python + FastAPI
- **数据库**：SQLite
- **部署**：单服务器，Nginx 反向代理

### 4.3 目录规范
| 内容 | 路径 |
|------|------|
| 前端代码 | `repos/frontend/` |
| 后端代码 | `repos/backend/` |
| 数据库文件 | `repos/db/` |
| 文档 | `docs/` |

## 6. Excel 格式规范

### 6.1 学生导入 Excel
| 第一列 | 第二列 |
|--------|--------|
| 学生姓名 | 学生学号 |
| 张三 | 001 |
| 李四 | 002 |

### 6.2 积分初始化 Excel
| 第一列 | 第二列 | 第三列 |
|--------|--------|--------|
| 学生姓名 | 学生学号 | 初始积分 |
| 张三 | 001 | 100 |
| 李四 | 002 | 80 |

### 6.3 结算导出 Excel
包含以下 Sheet：
- **排名**：班级所有学生按积分排名（姓名、学号、当前积分、排名）
- **明细**：所有加减分记录（学生姓名、学号、分值、原因、课程、操作教师、时间）

## 7. 业务流程图（结算）

```
开始
  │
  ▼
管理员选择班级
  │
  ▼
系统检查：学期是否已设置结束日期？
  │
  ├─ 未设置 → 弹出提示「请先在配置中设置学期结束日期」→ 结束
  │
  └─ 已设置
       │
       ▼
  当前日期 >= 学期结束日期？
       │
       ├─ 否 → 弹出提示「当前学期未结束，无法结算」→ 结束
       │
       └─ 是
            │
            ▼
      弹出确认码输入框
            │
            ▼
        确认码正确？
            │
            ├─ 否 → 弹出提示「确认码错误」→ 结束
            │
            └─ 是
                 │
                 ▼
          导出积分排名Excel
                 │
                 ▼
          逻辑删除积分记录
                 │
                 ▼
          重置学生当前积分为零
                 │
                 ▼
           结算完成提示
                 │
                 ▼
              结束
```
