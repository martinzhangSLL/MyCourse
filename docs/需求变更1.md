# 需求变更

## 1. 分值明细列表中，时间表示有问题

分值明细中，列表中时间的展示有问题，应该使用的是UTC标准时间计算的，我们对应的是东八区，应该加上8小时进行显示。

<br />

## 2. 积分的段位表示

积分需要分段位来表示，即多少分区间内的同学是什么段位，具体变更如下：

2.1 在管理页面中，新增一个段位管理，其中主要包括序号，段位名称，积分区间和对应图片。可以对段位进行增删改查，积分区间可以进行配置，小于多少分，介于多少分之间，大于多少分

2.2 初始化六个数据，分别是启灵境（<50），凝光境（51-100），逐风境（101-200），凌云境（201-300），摘星境（301-400），扶摇境（>401）,这六个数据对应的图片地址，已经放在repos/pic中，分别使用序号标识命名了

2.3 教师的分值管理页面，copy这个页面的功能，形成一个新的页面，不要动老的页面了，在新的页面中做修改。左侧的菜单栏添加一个新的目录- “班级分值”，导航到这个新的页面

2.4 页面的同学分值展示格中，把编号去掉，分值去掉，人名保留。根据当前的分值，去对应段位，展示响应段位的图片，并找到下一个序号，进行计算，说明还有多少分能升级
